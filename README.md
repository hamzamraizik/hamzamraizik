## Building software with a clear point of view

I’m a software engineer from Morocco focused on backend systems, product engineering, and AI-assisted workflows.

I like turning ambiguous ideas into dependable products—systems with clear boundaries, safe data, and interfaces that feel intentional.

### What I’m working on

- Deepening backend engineering and software architecture through deliberate practice.
- Building local-first business software for real operational workflows.
- Exploring AI products with practical fallbacks and well-defined system boundaries.
- Improving the bridge between robust backend behavior and thoughtful user experience.

### Selected work

- **[DigitalPro Systems IT](https://github.com/hamzamraizik/DigitalPro-Systems-IT)**  
  A responsive company website built with React, TypeScript, Vite, Tailwind CSS, and accessible UI components.

- **[Riḥla — Journey of the Soul](https://github.com/hamzamraizik/Rihla)**  
  An AI-powered travel itinerary generator for culturally immersive journeys through Morocco, combining Flask, Gemini, Qloo, and natural-language processing.

- **[Minishell](https://github.com/hamzamraizik/minishell)**  
  A systems-programming project focused on building shell behavior in C.

> Some of my current product work is private. The common thread is simple: useful software, carefully built.
